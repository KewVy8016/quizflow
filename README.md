# QuizFlow

เว็บฝึกทำข้อสอบจากไฟล์ JSON สำหรับทบทวนบทเรียนและเตรียมสอบ สร้างด้วย HTML, CSS และ JavaScript บันทึกความคืบหน้าในเบราว์เซอร์ และเผยแพร่เป็นเว็บ static ได้

## ความสามารถ

- เลือกภาคเรียน รายวิชา และช่วงสอบ Midterm / Final
- ค้นหาหัวข้อหรือวิชาในรายการที่เลือก
- กรองสถานะยังไม่ได้เริ่ม กำลังทำ หรือทำครบแล้ว
- เรียงตามรายวิชา ชื่อหัวข้อ หรือเวลาที่ทำล่าสุด
- กลับมาทำต่อ พร้อมจำตัวกรองเมื่อกลับจากหน้าข้อสอบ
- แสดงคำตอบที่ถูกและคำอธิบายทันทีหลังตอบ
- สลับลำดับคำถามและตัวเลือกผ่านเมนูตั้งค่าการฝึก
- แสดงความคืบหน้าจากจำนวนข้อที่ตอบจริง และสรุปคะแนนเมื่อทำครบ
- รองรับคอมพิวเตอร์และมือถือ รวมถึงการใช้งานด้วยคีย์บอร์ด

## เริ่มใช้งานในเครื่อง

ต้องมี Node.js สำหรับสร้างรายการข้อสอบ และ web server สำหรับเปิดเว็บ เพราะหน้าเว็บใช้ fetch โหลด JSON

จากโฟลเดอร์โปรเจกต์ รัน:

```powershell
npm run generate
```

เปิด web server ด้วย Python 3 หากติดตั้งไว้:

```powershell
python -m http.server 3000 --bind 127.0.0.1
```

หรือใช้ serve ผ่าน npm:

```powershell
npx serve . -l 3000
```

เปิด [http://127.0.0.1:3000](http://127.0.0.1:3000) ในเบราว์เซอร์ ไม่ควรเปิด index.html โดยดับเบิลคลิกไฟล์โดยตรง

## โครงสร้างโฟลเดอร์ข้อสอบที่แนะนำ

**1 ไฟล์ JSON = 1 ชุดข้อสอบ** และชื่อไฟล์เป็นชื่อหัวข้อที่แสดงบนการ์ด

ใช้โครงสร้าง:

```text
json/ภาคเรียน/ช่วงสอบ/วิชา/ไฟล์ข้อสอบ.json
```

ตัวอย่าง:

```text
json/
├── ปี 2 เทอม 1/
│   ├── Midterm/
│   │   ├── Cloud/
│   │   │   ├── Module 1 - Cloud Concepts.json
│   │   │   └── Module 2 - Cloud Economics.json
│   │   └── Advanced Network/
│   │       └── Chapter 1 - Introduction.json
│   └── Final/
│       ├── Cloud/
│       │   └── Module 8 - Databases.json
│       └── Advanced Network/
│           └── Chapter 9 - ICMP.json
└── ปี 2 เทอม 2/
    ├── Midterm/
    │   └── Database/
    │       └── Chapter 1 - Database Basics.json
    └── Final/
        └── Database/
            └── Chapter 5 - SQL.json
```

ระบบจะอ่าน:

| ส่วนของ path | ตัวอย่าง | การแสดงในหน้าเว็บ |
| --- | --- | --- |
| โฟลเดอร์แรกใต้ json/ | ปี 2 เทอม 1 | ภาคเรียน |
| โฟลเดอร์ก่อนชื่อวิชา | Midterm หรือ Final | ช่วงสอบ/กลุ่มเนื้อหา |
| โฟลเดอร์สุดท้ายก่อนชื่อไฟล์ | Cloud | รายวิชา |
| ชื่อไฟล์ | Module 1 - Cloud Concepts.json | ชุดข้อสอบ Module 1 - Cloud Concepts |

ชื่อภาคเรียนและวิชาตั้งเป็นภาษาไทยหรืออังกฤษได้ ไม่จำเป็นต้องเป็นชื่อที่มีอยู่แล้ว ใช้ชื่อวิชาให้เหมือนกันทั้ง Midterm และ Final เพื่อรวมอยู่ในเมนูวิชาเดียวกัน และใช้ชื่อช่วงสอบให้สม่ำเสมอ

โฟลเดอร์ว่างจะยังไม่แสดงในหน้าเว็บ ต้องมีไฟล์ .json อยู่ภายในก่อน

### เพิ่มวิชาใหม่

เช่น ต้องการเพิ่ม Database ในปี 2 เทอม 1:

1. สร้าง json/ปี 2 เทอม 1/Midterm/Database/
2. วางไฟล์ Chapter 1 - Database Basics.json ภายในโฟลเดอร์นั้น
3. ถ้ามีข้อสอบปลายภาค สร้าง json/ปี 2 เทอม 1/Final/Database/ แล้ววางไฟล์เพิ่ม
4. รัน npm run generate แล้ว refresh หน้าเว็บ

### เพิ่มภาคเรียนใหม่

เช่น ต้องการเพิ่มปี 3 เทอม 1:

1. สร้าง json/ปี 3 เทอม 1/
2. สร้าง Midterm/ชื่อวิชา/ และ Final/ชื่อวิชา/ ภายใน
3. วางไฟล์ข้อสอบในโฟลเดอร์วิชา
4. รัน npm run generate แล้ว refresh หน้าเว็บ

### ตำแหน่งวางไฟล์อื่นที่รองรับ

ตำแหน่งในตารางเป็น path ภายใน json/:

| ตำแหน่ง | ภาคเรียน | วิชา | ช่วงสอบ |
| --- | --- | --- | --- |
| ปี 2 เทอม 1/Midterm/Cloud/ชุดที่ 1.json | ปี 2 เทอม 1 | Cloud | Midterm |
| ปี 2 เทอม 1/Final/Cloud/ชุดที่ 2.json | ปี 2 เทอม 1 | Cloud | Final |
| ปี 2 เทอม 1/Cloud/ชุดฝึกทั่วไป.json | ปี 2 เทอม 1 | Cloud | ไม่ระบุ |
| ชุดฝึกทั่วไป.json | ทั่วไป | ทั่วไป | ไม่ระบุ |
| ปี 2 เทอม 1/ชุดฝึกทั่วไป.json | ปี 2 เทอม 1 | ปี 2 เทอม 1 | ไม่ระบุ |

แบบไม่ระบุช่วงสอบเหมาะกับแบบฝึกหัดทั่วไป การวางไฟล์ในโฟลเดอร์วิชาช่วยให้เมนูอ่านเข้าใจได้ง่ายกว่าไฟล์ที่อยู่ตรงใต้ภาคเรียน

### ลำดับโฟลเดอร์ที่ควรใช้

ใช้ **ภาคเรียน → ช่วงสอบ → วิชา → ไฟล์** เช่น:

```text
json/ปี 2 เทอม 1/Midterm/Cloud/Module 1.json
```

หากสลับเป็น ภาคเรียน/Cloud/Midterm/ไฟล์.json หน้าเว็บปัจจุบันจะอ่าน Midterm เป็นวิชา เพราะใช้ส่วนสุดท้ายของ subject path เป็นชื่อวิชา และส่วนก่อนหน้าเป็นกลุ่ม/ช่วงสอบ

หากต้องการแยกบท ให้สร้างหลายไฟล์ในโฟลเดอร์วิชาเดียวกัน แล้วใช้ชื่อ Chapter 1, Chapter 2 หรือ Module 1, Module 2 ไม่ควรเพิ่มโฟลเดอร์บทใต้โฟลเดอร์วิชา เพราะบทจะถูกอ่านเป็นชื่อวิชาแทน

## รูปแบบไฟล์ข้อสอบ JSON

ใช้ array ของคำถามอยู่ภายใน [] ไม่ต้องมี object ครอบด้วยชื่อ questions หรือ quiz

ตัวอย่างนี้ใช้ได้ทันที บันทึกเป็น Chapter 1 - Cloud Basics.json:

```json
[
  {
    "text": "ข้อใดอธิบาย Cloud Computing ได้ถูกต้อง?",
    "info": "Cloud Computing คือการให้บริการทรัพยากร IT ผ่านอินเทอร์เน็ตตามความต้องการ โดยมักคิดค่าบริการตามการใช้งานจริง",
    "difficulty": "easy",
    "answers": [
      {
        "text": "การใช้ทรัพยากร IT ผ่านอินเทอร์เน็ตตามความต้องการ",
        "correct": true
      },
      {
        "text": "การเก็บข้อมูลบนฮาร์ดดิสก์ส่วนตัวเท่านั้น",
        "correct": false
      },
      {
        "text": "การซื้อเซิร์ฟเวอร์มาใช้ภายในองค์กรเท่านั้น",
        "correct": false
      },
      {
        "text": "การใช้คอมพิวเตอร์โดยไม่เชื่อมต่อเครือข่าย",
        "correct": false
      }
    ]
  },
  {
    "text": "Pay-as-you-go หมายถึงอะไร?",
    "info": "Pay-as-you-go คือการจ่ายค่าบริการตามปริมาณทรัพยากรที่ใช้งานจริง",
    "difficulty": "easy",
    "answers": [
      {
        "text": "จ่ายตามการใช้งานจริง",
        "correct": true
      },
      {
        "text": "จ่ายจำนวนเท่ากันทุกครั้งโดยไม่ขึ้นกับการใช้งาน",
        "correct": false
      }
    ]
  }
]
```

### คำอธิบายฟิลด์

| ฟิลด์ | ชนิดข้อมูล | ความหมาย | จำเป็นหรือไม่ |
| --- | --- | --- | --- |
| text | string | ข้อความคำถาม | จำเป็น |
| answers | array | รายการตัวเลือก | จำเป็น |
| answers[].text | string | ข้อความตัวเลือก | จำเป็น |
| answers[].correct | boolean | คำตอบที่ถูกใช้ true ที่เหลือใช้ false | จำเป็น |
| info | string | คำอธิบายหลังตอบ | แนะนำให้มี |
| difficulty | string | easy, medium หรือ hard | ไม่บังคับ |

หน้าเว็บให้เลือกคำตอบครั้งละหนึ่งตัวเลือก จึงควรกำหนด **correct: true เพียงหนึ่งตัวเลือกต่อคำถาม** ตัวเลือกไม่จำเป็นต้องมีสี่ข้อเสมอไป แต่ควรมีอย่างน้อยสองตัวเลือก

จำนวนคำถามไม่จำเป็นต้องเป็น 30 ข้อ ใช้ได้ตามจำนวนในไฟล์ โดยต้องมีอย่างน้อยหนึ่งคำถาม

ถ้าไม่ระบุ info หน้าเว็บจะแสดงว่า “ไม่มีคำอธิบาย” ส่วน difficulty ยังไม่ได้ใช้แสดงหรือกรองใน UI ปัจจุบัน

คำถาม ตัวเลือก และคำอธิบายแสดงเป็นข้อความธรรมดา ไม่ใช้ HTML จึงควรเขียนคำอธิบายโดยไม่ใส่แท็ก HTML

### กฎการเขียน JSON

- ใช้เครื่องหมาย double quote สำหรับชื่อฟิลด์และข้อความ
- ใช้ true / false โดยไม่มีเครื่องหมายคำพูด
- ไม่ใส่ comment หรือ comma หลังรายการสุดท้าย
- ถ้าในข้อความมีเครื่องหมาย double quote ให้ escape เป็น backslash ตามด้วย double quote
- บันทึกไฟล์เป็น UTF-8
- ใช้นามสกุล .json ตัวเล็ก เพราะสคริปต์สร้างรายการตรวจนามสกุลนี้
- แยกไฟล์ตามบทหรือหัวข้อ เช่น Chapter 1 - Introduction.json
- ชื่อหัวข้อบนการ์ดมาจากชื่อไฟล์ โดยตัด .json และเปลี่ยน underscore เป็นช่องว่าง

## หลังเพิ่ม แก้ชื่อ ย้าย หรือลบไฟล์ข้อสอบ

รันในโฟลเดอร์โปรเจกต์:

```powershell
npm run generate
```

คำสั่งนี้อ่านโฟลเดอร์ย่อยทั้งหมดแล้วสร้าง [quiz-list.json](quiz-list.json) ใหม่ จากนั้น refresh หน้าเว็บ ไม่ต้องเพิ่มเมนูด้วยการแก้ HTML และไม่ต้องแก้ quiz-list.json เอง

การแก้เฉพาะข้อความหรือคำอธิบายในไฟล์เดิมไม่จำเป็นต้องสร้างรายการใหม่ แต่ควรโหลดหน้าข้อสอบใหม่เพื่ออ่านเนื้อหาที่แก้

หากมีการเปลี่ยนจำนวนหรือลำดับคำถาม/ตัวเลือกในชุดที่เคยทำแล้ว ควรใช้ “เริ่มชุดนี้ใหม่” เพราะคำตอบปัจจุบันบันทึกตามตำแหน่งคำถามและตัวเลือก

### คำสั่งที่ใช้ได้

| คำสั่ง | หน้าที่ |
| --- | --- |
| npm run generate | อ่านโครงสร้างโฟลเดอร์ทั้งหมดและสร้าง quiz-list.json |
| npm run convert | แปลงไฟล์แบบเก่าที่มี quiz_id เฉพาะไฟล์ที่อยู่ตรงใต้ json/ |
| npm run setup | รัน convert แล้ว generate |
| npm run build | รัน setup |

สำหรับไฟล์รูปแบบที่แนะนำใน Midterm/Final ใช้ npm run generate ได้เลย สคริปต์ convert ปัจจุบันยังไม่ได้สแกนโฟลเดอร์ย่อย และการแปลงจะเขียนทับไฟล์ต้นฉบับที่เข้าเงื่อนไข

ใน package.json ยังมีคำสั่ง watch และ dev ที่อ้างถึง watch-and-convert.js รวมถึง dev:simple ที่ต้องมีคำสั่ง serve อยู่ในเครื่อง แต่ไฟล์ watcher และ start-dev.bat ไม่ได้รวมอยู่ใน repository นี้ ให้ใช้วิธีเปิด web server และสร้างรายการด้วยตนเองตามคู่มือนี้

## วิธีใช้หน้าเว็บ

1. เลือกภาคเรียนและรายวิชา หรือเลือกทุกภาคเรียน/ทุกวิชา
2. ค้นหาหัวข้อ กรองสถานะ หรือเลือก Midterm / Final
3. เปิดชุดข้อสอบแล้วเลือกคำตอบ ระบบจะแสดงคำตอบที่ถูกและคำอธิบาย
4. กดข้อถัดไป เมื่อทำครบกดดูผลคะแนน
5. กลับมาที่เมนูทำต่อเพื่อเปิดชุดที่ยังทำไม่ครบ

การค้นหาใช้เฉพาะภาคเรียน วิชา และตัวกรองที่เลือกไว้ มีขอบเขตแสดงในบรรทัดจำนวนผลลัพธ์ กด “ล้างตัวกรอง” เพื่อค้นหาทุกวิชาและทุกภาคเรียน

เมนู “ตั้งค่าการฝึก” ใช้เปิด/ปิดการสลับลำดับคำถามและตัวเลือก รวมถึงเริ่มชุดนั้นใหม่ เปลี่ยนการสลับลำดับคำถามจะกลับไปข้อแรกและเก็บคำตอบที่ทำแล้วไว้

## ความคืบหน้าและข้อจำกัด

- บันทึกข้อมูลใน localStorage ของเบราว์เซอร์และ origin ที่ใช้งาน ไม่มีการซิงก์ข้ามอุปกรณ์
- ตัวกรองหน้า library บันทึกใน sessionStorage สำหรับแท็บนั้น
- บันทึกความคืบหน้าใหม่โดยใช้ path เต็มของไฟล์ เพื่อแยกข้อสอบชื่อเดียวกันคนละโฟลเดอร์
- เปลี่ยนชื่อหรือย้ายไฟล์จะได้ path ใหม่ และจะไม่ดึงความคืบหน้าจาก path เดิมโดยอัตโนมัติ
- ข้อมูลจากเวอร์ชันเก่าที่ใช้ชื่อไฟล์เป็น key ยังอ่านได้ แต่ต้องเปิดชุดอีกครั้งเพื่อบันทึกจำนวนข้อทั้งหมดและระบุสถานะทำครบแล้ว
- ถ้าข้อมูลเก่าเคยชนกันเพราะชื่อไฟล์ซ้ำ ระบบไม่สามารถระบุย้อนหลังได้ว่าคำตอบเป็นของไฟล์ใด
- การล้างข้อมูลเว็บไซต์หรือใช้เบราว์เซอร์อื่นทำให้ไม่เห็นความคืบหน้าที่บันทึกไว้เดิม
- ใช้ Noto Sans Thai จาก Google Fonts พร้อม system font สำรองเมื่อโหลดฟอนต์ไม่ได้

## เผยแพร่บน Vercel

repository มี [vercel.json](vercel.json) กำหนด build command ไว้แล้ว:

```text
node convert-quiz-format.js && node generate-quiz-list.js
```

หลังเชื่อม repository กับ Vercel ระบบจะสร้างรายการข้อสอบตอน build และเผยแพร่เว็บ static จากโฟลเดอร์โปรเจกต์

เมื่อเพิ่มข้อสอบและต้องการส่งขึ้น Git:

```powershell
npm run generate
git add json/ quiz-list.json
git commit -m "Add new quiz topics"
git push
```

หากเปิด automatic deployment ของ Vercel ไว้ การ push ไปยัง branch ที่เชื่อมไว้จะเริ่ม deployment ตามการตั้งค่าของโปรเจกต์

## แก้ปัญหาเบื้องต้น

| อาการ | สิ่งที่ควรตรวจ |
| --- | --- |
| วิชาหรือภาคเรียนใหม่ไม่ปรากฏ | มีไฟล์ .json ในโฟลเดอร์แล้วหรือยัง รัน npm run generate แล้วหรือยัง |
| เพิ่มชุดแล้วค้นหาไม่พบ | กดล้างตัวกรอง ตรวจภาคเรียน วิชา ช่วงสอบ และสถานะ |
| ชื่อวิชากลายเป็น Midterm หรือชื่อบท | ตรวจลำดับโฟลเดอร์ ให้ชื่อวิชาเป็นโฟลเดอร์สุดท้ายก่อนชื่อไฟล์ |
| เปิดชุดแล้วโหลดไม่สำเร็จ | ตรวจว่า JSON ถูกต้อง เป็น array ไม่ว่าง แต่ละคำถามมี answers และ path ในรายการตรงกับไฟล์จริง |
| เปิดไฟล์ HTML แล้วไม่โหลดข้อสอบ | เปิดผ่าน web server ตามขั้นตอนเริ่มใช้งาน |
| แก้คำถามแล้วคำตอบเก่าไม่ตรง | ใช้เมนูเริ่มชุดนี้ใหม่ |
| รัน npm run generate ไม่ได้ | ตรวจว่ามี Node.js และอยู่ในโฟลเดอร์ที่มี package.json |

## โครงสร้างโปรเจกต์

```text
quizflow/
├── index.html                 # คลังแบบฝึกหัด
├── quiz.html                  # หน้าทำข้อสอบและผลคะแนน
├── style.css                  # รูปแบบหน้าเว็บและ responsive layout
├── library.js                 # เมนู ค้นหา ตัวกรอง และการ์ดข้อสอบ
├── quiz.js                    # คำถาม เฉลย การสลับ และคะแนน
├── storage.js                 # อ่านและบันทึกความคืบหน้า
├── generate-quiz-list.js       # สร้างรายการจากโฟลเดอร์แบบ recursive
├── convert-quiz-format.js      # แปลงไฟล์แบบเก่าที่อยู่ตรงใต้ json/
├── quiz-list.json             # รายการที่สร้างจากสคริปต์
├── package.json               # คำสั่ง npm
├── vercel.json                # การตั้งค่า build และเผยแพร่
├── README.md                  # คู่มือใช้งานปัจจุบัน
├── UI-IMPROVEMENTS.md          # บทวิเคราะห์ UI และแนวทางพัฒนาต่อ
└── json/                      # ไฟล์ข้อสอบ
```
